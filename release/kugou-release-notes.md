# 都市回响 v0.8.0-beta.5-kugou.1 · 暂停时隐藏歌词

暂停时隐藏（v0.8.0-beta.5）：在“歌词效果 → 律动与同步”勾选“暂停播放时隐藏歌词”。网易云、QQ 音乐和酷狗版均支持，默认关闭；开启后暂停即隐藏，继续播放按当前进度显示；关闭时保留暂停冻结。修改立即生效并自动保存，不随效果预设切换；手动隐藏后不会因恢复播放而弹出。不改变音乐播放或进度，设置页的独立动画预览仍可使用。

酷狗 `.2` 修复合作歌曲匹配：系统媒体只提供主歌手，但原生歌词／缓存包含客串歌手时，仅在双方完整歌名一致、歌名明确写明 feat./ft./featuring、其余歌手完全对应时接受。未署名合作、不同主歌手、现场／翻唱版本或哈希冲突仍拒绝；没有扩大时长容差或修改酷狗播放回调。

本版新增“延长歌词显示”：在“歌词效果 → 律动与同步”勾选“新句出现后保留旧句”，默认关闭，开启后时长默认 10 秒、范围 1–120 秒，从句首计算并包含退场。最多四组（双语算一组），空间不足优先新句，空白段与歌曲结束清除；原最长显示上限保留数值但暂停生效，不随预设切换。

歌词继续始终置顶，不增加开关；被其他不透明置顶窗口覆盖时恢复且不抢焦点。独占全屏游戏、系统安全桌面不能保证。酷狗增加迟到缓存重查、精确哈希定位及可区分原因的匹配失败提示，官方接口无候选仍需可用本地歌词。保留设置、字体、预设和原播放方式；本地循环与 OBS 输出未改动。

本版修复：乱码退场切句时旧歌词停住、下一句闪现的问题。字号适配和逐字发光材质改为帧间分批准备，保留原动画、音乐进度与个人设置。更新前退出歌词程序，完整解压并替换全部程序文件，保留设置、导入字体和预设。

同步共享引擎 v0.8.0-beta.5：新增“歌词最长显示时间”，默认 6 秒、0–120 秒可调，0 不额外限制，包含退场。长句可调长或关闭，未知末句仍保留 6 秒兜底；切换效果预设不重置。修复纯音乐附带作曲／编曲署名时不能隐藏，优化下一句预载和长句分批材质准备。晚到歌词不重置音乐进度补播。

基于 CAR0TT0 的 PR #4，修复酷狗最小化后歌词断连：系统歌手名 `Mili` 与原生歌词 `Mili（ミリー）` 被误判为不同歌手，后台通道无法使用。现在接受可靠跨文字体系别名，同时保留合唱、现场、翻唱、版本、时长及歌词哈希校验。

下载 `dancing-lyrics-0.8.0-beta.5-kugou.1-windows-x64.zip`，完整解压，打开酷狗播放歌曲并开启桌面歌词，再双击“启动酷狗联动.bat”。无需 Python、Git、BetterNCM 或管理员权限；可选“安装酷狗联动.bat”创建个人快捷方式。状态显示原生歌词通道或系统媒体接口时可最小化，界面兼容回退仍需要展开主窗口。

保留渐变、双语、乱码退场、字体导入、主题、预设、屏幕选择及纯音乐隐藏。设置和字体继续使用 `%LOCALAPPDATA%\DancingLyrics-Kugou\.state`。升级前退出旧歌词程序，保留该目录；从新目录重装快捷方式，自动联动应在旧版关闭后从新版重新开启。

本机验证范围为 Windows x64、酷狗 20.1.51.27967。真实最小化、托盘隐藏、冷启动和显示恢复记录见仓库验证记录；没有用模拟歌曲代替实曲。不同内部结构、32 位客户端及第二台干净电脑尚未验证，不承诺所有未来版本均兼容。网易云／QQ 请使用对应的 v0.8.0-beta.5 独立包；Mac 的现有实验成品保持原版。
