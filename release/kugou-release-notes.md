# 都市回响 v0.8.0-beta.3-kugou.1 · 显示时限与长句渐入

本版修复：乱码退场切句时旧歌词停住、下一句闪现的问题。字号适配和逐字发光材质改为帧间分批准备，保留原动画、音乐进度与个人设置。更新前退出歌词程序，完整解压并替换全部程序文件，保留设置、导入字体和预设。

同步共享引擎 v0.8.0-beta.3：新增“歌词最长显示时间”，默认 6 秒、0–120 秒可调，0 不额外限制，包含退场。长句可调长或关闭，未知末句仍保留 6 秒兜底；切换效果预设不重置。修复纯音乐附带作曲／编曲署名时不能隐藏，优化下一句预载和长句分批材质准备。晚到歌词不重置音乐进度补播。

基于 CAR0TT0 的 PR #4，修复酷狗最小化后歌词断连：系统歌手名 `Mili` 与原生歌词 `Mili（ミリー）` 被误判为不同歌手，后台通道无法使用。现在接受可靠跨文字体系别名，同时保留合唱、现场、翻唱、版本、时长及歌词哈希校验。

下载 `dancing-lyrics-0.8.0-beta.3-kugou.1-windows-x64.zip`，完整解压，打开酷狗播放歌曲并开启桌面歌词，再双击“启动酷狗联动.bat”。无需 Python、Git、BetterNCM 或管理员权限；可选“安装酷狗联动.bat”创建个人快捷方式。状态显示原生歌词通道或系统媒体接口时可最小化，界面兼容回退仍需要展开主窗口。

保留渐变、双语、乱码退场、字体导入、主题、预设、屏幕选择及纯音乐隐藏。设置和字体继续使用 `%LOCALAPPDATA%\DancingLyrics-Kugou\.state`。升级前退出旧歌词程序，保留该目录；从新目录重装快捷方式，自动联动应在旧版关闭后从新版重新开启。

本机验证范围为 Windows x64、酷狗 20.1.51.27967。真实最小化、托盘隐藏、冷启动和显示恢复记录见仓库验证记录；没有用模拟歌曲代替实曲。不同内部结构、32 位客户端及第二台干净电脑尚未验证，不承诺所有未来版本均兼容。网易云／QQ 请使用对应的 v0.8.0-beta.3 独立包；Mac 的现有实验成品保持原版。
