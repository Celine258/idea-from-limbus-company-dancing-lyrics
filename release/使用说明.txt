都市回响 0.8.0-beta.3（Windows x64 试用版）

本版修复：乱码退场切句时旧歌词停住、下一句闪现的问题。字号适配和逐字发光材质改为帧间分批准备，保留原动画、音乐进度与个人设置。更新前退出歌词程序，完整解压并替换全部程序文件，保留设置、导入字体和预设。

本版新增：在“歌词效果 → 律动与同步”设置“歌词最长显示时间”，默认 6 秒，0–120 秒可调，0 表示不额外限制。时限包含入场和退场，长句可调长或关闭，未知末句仍保留 6 秒兜底；切换效果预设不会重置。纯音乐含作曲／编曲署名时也可隐藏，混有正常歌词时不猜测。长句分批预载，歌词迟到时不重置歌曲进度补播动画。

请选择独立的 QQ 音乐版或网易云音乐版 ZIP。两份包使用不同解压目录、入口和使用说明。
本文件是源码仓库中的总说明；成品 ZIP 会放入对应播放器的专用说明。
网易云新增自动兼容检测、联网刷新兼容列表和实验性安装。未验证版本需单次确认，已知不兼容禁止安装。
实验性安装不能保证未来版本都可用；出现问题先退出网易云，再运行“恢复网易云联动.bat”恢复上次安装。
从旧通用包升级时，先退出旧程序，将原 .state 整个复制到对应新目录；网易云版需再次安装联动。

QQ 音乐（已验证 22.52／22.75，同一份 QQ 音乐版 ZIP）：
打开 QQ 音乐播放歌曲，双击“启动QQ音乐联动.bat”，无需 Python 或 BetterNCM。
首次打开 BAT 后，可在“当前音乐 → QQ 音乐自动联动”勾选“随 QQ 音乐启动”，默认关闭。
开启后在 Windows 登录时运行监听，QQ 启动后自动显示歌词，设置收在托盘；重复打开 BAT 复用窗口。
关闭开关后约 2 秒停止监听。更新或删除前先关闭开关并退出歌词；移动目录后从新目录重新开启。
QQ 播放栏不增加按钮，音乐仍由 QQ 音乐播放。
完整保留 _internal 文件夹。需要 Windows 10 1809+，请开启 QQ 音乐系统媒体控制。
歌词只读跟随，音乐、暂停、进度、切歌和音量均在 QQ 音乐操作。
优先读取 QQ 本地 QRC 缓存，未命中联网访问 QQ 官方歌词接口，严格匹配原歌曲；失败时点击“重新获取歌词”。
组合搜索失败时依次回退仅歌名及歌手在前的搜索（最多三种不同查询），仍严格核对歌手、专辑和时长。
本地 QRC 支持真实字词演唱强调及可用中文译文；无缓存时回退整句 LRC，纯音乐保持空白。
“当前音乐”可选择 QQMusicLyricNew 缓存目录，或恢复自动查找；首次取词速度仍受 QQ 写盘和网络影响。
同一时间请选择 QQ 或网易云入口，避免两个歌词实例重复显示。


三步开始
1. 完整解压 ZIP 到准备长期保留且自己可写的目录，例如 D:\Apps\DancingLyrics。
2. 完全退出网易云（包括托盘），双击“安装网易云联动.bat”，点击“安装联动”。
3. 重新打开网易云，点击播放栏的“都市回响”；右键或点旁边“设置”调整字体、动画和主题。

请保留 FloatingLyrics.exe 旁的 _internal 文件夹。无需安装 Python 或 Git。
同一个 ZIP 自动识别网易云 3.1.40.205461／3.1.41.205529 x64，无需分别选择安装包。
已验证：Windows 11 x64、以上两个网易云版本、BetterNCM 1.3.4。
其他网易云版本会停止安装并提示原因，不能保证兼容。

找不到网易云时手动选择 cloudmusic.exe 所在目录。
BetterNCM 数据目录请保留默认 C:\betterncm，或选择英文路径；含中文的数据路径会停止安装并提示。
歌词程序及网易云本身可以放在中文目录，该限制只涉及 BetterNCM 1.3.4 的插件数据路径。
安装到需要写入权限的目录时，窗口会提供“以管理员身份重试”，请按 Windows 提示授权。
不要把程序放进 Program Files 等无法写入个人设置的目录。
首次缺少框架需联网，从固定官方地址下载并验证 SHA-256；已有相同版本不会重复下载。
网络失败时可先从 https://github.com/std-microblock/chromatic/releases/tag/1.3.4 下载 BetterNCMII.dll，
在安装窗口选择“本地框架 DLL”。不要下载来源不明或不同版本的 DLL。

更新
退出网易云和歌词程序，把新 ZIP 解压覆盖原目录，再运行安装入口。
不要删除或覆盖原 .state 文件夹，其中有设置、字体、预设和本机连接配置。
安装后不要移动程序；移动后必须退出网易云并在新目录再次安装，以更新启动路径。

卸载
完全退出网易云，双击“卸载网易云联动.bat”。只移除本歌词插件，保留 .state 和共用框架。
如不再需要个人设置，在退出歌词程序后可自行删除整份程序目录。

本地音乐
“启动.bat”可打开独立界面，导入本地音乐与同名 LRC；网易云联动只负责歌词效果，音乐由网易云播放。
纯音乐保持原处理，不生成假歌词。逐字强调仅使用当前歌曲能可靠匹配的时间数据。

新增效果使用方法

- 渐变描边：歌词效果 → 白芯发光 → 渐变描边；字芯保持白色。渐变字芯：文字样式 → 渐变字芯，描边与光晕仍用单色。可选两色、添加中间色及横向／纵向／斜向渐变，立即预览、保存，可存为效果预设。
- 歌词语言：原文／中文优先／双语·原文在上／双语·译文在上。下方文字为上方的 80%，无有效译文显示原文；译文仅按句同步，不套用原文逐字时间。
- 乱码退场：在律动与同步中开启，替代原退场；原字符依次变成符号后从左向右消失。复用退场速度，暂停冻结、跳转直接重建。
- 显示屏幕：选择主屏自动跟随或指定显示器；断开暂用主屏，重连后恢复。无序列号设备重新枚举后可能需要重选。
- 纯音乐时不显示歌词或提示：默认关闭；开启后隐藏来源明确的纯音乐标记／提示，不根据歌曲名称或暂未获取歌词猜测。无歌词仍为空白。
- 滚轮只浏览页面，不再修改下拉框、数字和滑块；保留点击、输入、拖动与键盘操作。语言、屏幕及纯音乐开关不随效果预设切换。
