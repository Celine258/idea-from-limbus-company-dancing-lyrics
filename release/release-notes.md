# 都市回响 v0.5.1-beta.1

首个公开试用版。下载 `dancing-lyrics-0.5.1-beta.1-windows-x64.zip`，无需安装 Python。
页面自动生成的 **Source code** 是源码，不是成品安装包。

1. 完整解压到长期保留且可写的目录。
2. 完全退出网易云（包括托盘），双击“安装网易云联动.bat”，点击安装。
3. 重开网易云，在播放栏点击“都市回响”；右键或点击“设置”调整效果。

支持逐字波纹／跌落、字体导入、白芯发光、效果预设、可用歌曲的逐字演唱强调，
以及默认／深色／特殊主题。音乐由网易云播放，纯音乐保持原处理。

本机已验证 Windows 11 x64、网易云 **3.1.41.205529 x64**、BetterNCM **1.3.4**。
其他网易云版本停止安装并显示原因。首次缺少框架需要联网下载官方 DLL；网络失败可手动选择官方文件。
安装后的程序目录不要移动；移动或更新后重新运行安装入口。

更新：退出网易云和歌词程序，新包覆盖原目录，再运行安装；保留 `.state`。
卸载：退出网易云，运行“卸载网易云联动.bat”；保留个人数据和共用 BetterNCM 框架。

已完成自动测试、本机独立解压成品安装／更新／卸载、双击入口与网易云播放回归。
尚未在第二台无开发环境电脑或干净虚拟机完成独立试装，请先小范围试用。

附 SHA-256 文件供核对 ZIP 完整性。问题请通过仓库 Issues 反馈版本、复现步骤与截图，
不要上传 `.state/netease-bridge.json`。
