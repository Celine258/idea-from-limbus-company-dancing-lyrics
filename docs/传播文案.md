# 首次发布传播材料

## 30 秒演示脚本

| 时间 | 画面 | 字幕 |
| --- | --- | --- |
| 0–6 秒 | 在代码编辑器旁展示桌面歌词 | 写代码时，让歌词陪你跳一会儿 |
| 6–13 秒 | 网易云播放栏打开“都市回响”，进入设置 | 音乐由网易云播放，歌词效果独立显示 |
| 13–20 秒 | 波纹、跌落；切换安静办公／轻快律动 | 逐字动画、字体发光，也能保存自己的方案 |
| 20–26 秒 | 默认、深色、特殊主题；展示但丁钟头 | FACE THE SIN. SAVE THE E.G.O |
| 26–30 秒 | 安装 ZIP 三步说明与下载地址 | 下载 → 解压 → 双击安装；简介里有链接 |

优先使用原创合成演示音频或有权使用的歌曲片段。演唱强调预览标注“演示时间”，
实际网易云支持情况按歌曲提供的字词数据说明。录制及上传 Bilibili 由创作者完成。

## 简介与置顶评论

做了一个 Windows 桌面歌词小工具“都市回响”：音乐仍由网易云播放，歌词会逐字出现、
波动或抖动，再逐字淡出或跌落。支持字体导入、白芯发光、效果预设和三种主题。
特殊主题参考 Limbus Company；这是个人制作的工具。

下载试用版：
https://github.com/Celine258/idea-from-limbus-company-dancing-lyrics/releases/tag/v0.5.1-beta.1

安装只需三步：完整解压 ZIP → 退出网易云并双击“安装网易云联动.bat” → 重开网易云。
目前已验证 Windows 11 x64、网易云 3.1.41.205529 x64。其他版本暂不保证兼容。
请下载页面里的 dancing-lyrics-0.5.1-beta.1-windows-x64.zip，不要下载 Source code 当成安装包。
